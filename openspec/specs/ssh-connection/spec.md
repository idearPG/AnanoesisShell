# Linux SSH 连接规格

## Purpose

提供连接内网 Linux 服务器并进行交互式终端操作的能力（add-multi-session-agent-terminal 后范围为多台服务器、同一服务器可多路并发独立连接），覆盖服务器连接配置的管理、SSH 连接的建立与认证、实时双向的交互式终端会话，以及连接会话的生命周期与资源释放。

## Requirements

### Requirement: 服务器配置管理

系统 SHALL 允许用户创建、查看、修改、删除 Linux 服务器连接配置；每项配置 MUST 包含主机地址、端口、登录用户名、认证方式（密码或私钥），并 MAY 包含分组或备注标签。

#### Scenario: 新增服务器配置

- **WHEN** 用户填写主机地址、端口、用户名与认证凭据并保存
- **THEN** 系统持久化该配置并在服务器列表中展示

#### Scenario: 编辑既有配置

- **WHEN** 用户修改某台服务器配置的字段并保存
- **THEN** 系统更新该配置，且后续连接使用更新后的值

#### Scenario: 删除配置

- **WHEN** 用户删除某台服务器配置
- **THEN** 系统移除该配置且不再展示于服务器列表

### Requirement: 建立 SSH 连接

系统 SHALL 使用已保存的配置与对应凭据向目标 Linux 服务器发起 SSH 连接，并在认证成功时建立可用会话；认证失败或主机不可达时 MUST 返回明确的错误原因，且不得泄露服务器内部细节。

#### Scenario: 密码认证成功

- **WHEN** 用户使用有效的密码凭据发起连接
- **THEN** 系统建立 SSH 会话并进入就绪状态

#### Scenario: 私钥认证成功

- **WHEN** 用户使用有效的私钥（含 passphrase）发起连接
- **THEN** 系统建立 SSH 会话并进入就绪状态

#### Scenario: 认证失败

- **WHEN** 用户提供的凭据无效
- **THEN** 系统拒绝连接并提示"认证失败"，不暴露服务器内部细节

#### Scenario: 主机不可达

- **WHEN** 目标主机地址或端口不可达
- **THEN** 系统在超时后提示"连接失败：主机不可达"

### Requirement: 交互式终端会话
系统 SHALL 为每个独立连接提供持久交互式终端，支持用户输入命令、实时流式回显输出，并正确呈现常见交互行为（彩色输出、光标控制、中断信号）。人工与 Agent 命令 SHALL 使用所属连接的同一持久 Shell；PTY 输出按合流处理，不承诺拆分标准输出与标准错误。经审批的 `run_command` 执行超时 SHALL 为 1800 秒（30 分钟），空闲超时（无 stdout/stderr 输出）SHALL 为 120 秒作为心跳检测。

#### Scenario: 命令实时回显
- **WHEN** 用户在终端输入命令并回车
- **THEN** 系统流式展示该命令经 PTY 合流后的标准输出与标准错误，不重复渲染同一份执行输出

#### Scenario: 交互式程序可用
- **WHEN** 用户运行需要交互的程序（如 top、vim）
- **THEN** 终端正确渲染其界面并转发用户的按键输入，此时不接受 Agent 自动命令注入

#### Scenario: 中断运行中的命令
- **WHEN** 用户发送中断信号（Ctrl-C）
- **THEN** 系统将该信号转发至远端前台命令；只有取得结束证据才标记为终止，不能确认时明确显示状态未知

#### Scenario: AI 下载大文件不超时
- **WHEN** AI 代理通过 `run_command` 执行 wget/curl 下载大文件，下载过程持续产生输出（进度条）
- **THEN** 命令在 30 分钟内不被执行超时中断；watchdog 因持续收到输出而不断重置空闲计时器

#### Scenario: 下载假死被心跳检测
- **WHEN** `run_command` 执行过程中远端连续 120 秒无任何 stdout/stderr 输出
- **THEN** 空闲超时触发，系统向远端发送 Ctrl-C 中断命令，模型收到超时反馈

### Requirement: 连接会话生命周期
系统 SHALL 记录每个独立连接会话的开始与结束，并在用户主动断开、连接超时或远端关闭时释放所属 PTY、自动任务及 SFTP 资源。相同服务器的不同连接 MUST 独立管理；关闭不自动删除对话历史或重放命令。

#### Scenario: 主动断开
- **WHEN** 用户关闭某个终端会话
- **THEN** 系统断开对应 SSH 连接并释放其占用的资源，不影响其他连接实例，保存本次结束原因与未完成任务状态

#### Scenario: 远端关闭连接
- **WHEN** 远端服务器主动断开连接
- **THEN** 系统提示连接已结束并清理本地会话状态，使关联审批失效、传输停止；未确认完成的命令明确标为结果未知

### Requirement: 终端集成静默安装
系统 SHALL 在支持的 Shell（Bash 4+）会话建立时安装命令边界集成钩子；安装 MUST 在用户终端静默完成——不留下安装代码回显、续行提示符或控制帧字面文本（实现：回显抑制与钩子设置 MUST 合并为**单条命令行**一次性发送——每条命令行都会触发一次 PROMPT_COMMAND/提示帧，分次发送会在闸门开闸后多弹提示符造成双 prompt；钩子设置压缩为单行、生成代码的 printf 转义 MUST 产出真实 ESC 字节而非 `\033` 字面文本、服务端输出闸门在首个有效集成帧前吞掉一切转发输出并带超时兜底）。噪声抑制的保护起点 MUST 是会话的**第一个输出字节**：登录 banner 与首个提示符可能在闸门接入前就到达读泵，MUST 由预安装静音吞掉（竞态防御；双 prompt 的真根因是分段发送，见 known-issues #19）；静音窗口内会话终结事件（closed）MUST 照常透传。安装异常降级时输出链 MUST 恢复原样透传，不得把用户终端永久静音。安装语句 MUST 在当前交互 Shell 内生效（非子 Shell），保留既有钩子；不受支持的 Shell 明确降级不隐式回退，且不动输出闸门（登录 banner 照常透传人工终端）。用户在集成安装前已粘贴的输入不得被安装序列吞入。

#### Scenario: 首次连接无安装噪声
- **WHEN** 用户首次建立 Bash 会话并观察终端
- **THEN** 终端仅出现安装完成后闸门放行的那一个提示符（闸门被首个真实帧开启后立即转发，不靠超时兜底；安装序列为单条命令行，整行只弹一个 prompt），不出现同一行双提示符、登录 banner/首 prompt 的泄漏叠加、钩子定义代码、`>` 续行提示、`\033]1337;` 字面帧文本或 `command not found` 噪声；后续人工命令仍正常产生命令边界事件供调度器识别

#### Scenario: 集成在当前 Shell 生效
- **WHEN** 集成安装完成后用户执行 `cd` 切换目录
- **THEN** 所属会话的命令边界与目录状态由该交互 Shell 的钩子上报（设置不随子 Shell 退出丢失），供获准命令路由回同一环境

### Requirement: 远端终端尺寸同步
系统 SHALL 将每个可见终端的行列变化传递到所属远端 PTY，支持窗口缩放及从后台 tab 恢复显示；终端首次连接建立、以及前端终端实例（重）挂载或采纳既有会话时，MUST 主动补发一次当前真实行列——不得依赖用户手动缩放窗口才触发同步（远端 PTY 停留在默认 80x24 而本地按实际尺寸排版时，readline 类程序的方向键历史回读会跨行重排、渲染全乱）；尺寸变化不得影响其他连接，隐藏实例不得被发送零尺寸。

#### Scenario: 首连即同步真实尺寸
- **WHEN** 用户新建连接进入终端且从未手动改变窗口大小
- **THEN** 远端 PTY 的行列与本地可见终端一致（远端 `stty size` 可核对），切回 Shell 模式按上/下方向键调取历史命令时光标重排正常、终端渲染不出现叠行错乱

#### Scenario: 调整窗口或切回终端
- **WHEN** 终端窗口大小变化或后台 tab 重新显示
- **THEN** 该实例使用当前有效行列调整远端 PTY，top/vim 正确重排，隐藏实例不被发送零尺寸
