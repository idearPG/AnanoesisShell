# sftp-transfer Specification

## Purpose
提供用户本地电脑与已连接 Linux 服务器之间的 SFTP 双向文件传输，支持在连接工作区浏览远端目录、选择文件上传和下载，并以可取消的有界传输与清晰的覆盖和失败语义保护文件及其他终端连接。

## Requirements

### Requirement: 连接内远端文件浏览
系统 SHALL 在每个连接工作区提供远端文件面板，显示当前路径、名称、类型、大小及修改时间，支持进入目录、返回父目录、刷新和有界加载更多；数据和操作目标 MUST 绑定连接实例。服务端不支持 SFTP 时必须明确报错，不隐式回退其他协议。

#### Scenario: 同主机两个连接浏览不同目录
- **WHEN** A #1 打开 /var/log，A #2 打开其用户目录
- **THEN** 两个面板分别保留路径与状态，在其中一处上传或刷新不会把请求发送到另一连接

#### Scenario: 超大目录或无权限目录
- **WHEN** 远端目录包含大量条目或用户无权访问
- **THEN** 系统以有界批次读取并提供继续加载，或返回明确的权限错误，不无限占用内存或伪装为空目录

### Requirement: 本地文件上传到远端
系统 SHALL 允许用户通过本地文件选择器选择一个或多个普通文件，上传到当前明确显示的 Linux 目录；每个文件有独立任务状态和进度，默认不覆盖既有目标。本期不递归上传目录。

#### Scenario: 上传单个或多个文件
- **WHEN** 用户确认目标目录并选择本地普通文件开始上传
- **THEN** 文件内容通过 SFTP 写入该连接目标，界面区分已发送与远端已完成，成功后可刷新查看并验证内容一致

#### Scenario: 同名文件需要覆盖
- **WHEN** 目标普通文件已存在
- **THEN** 系统暂停该文件并明确要求覆盖确认，未确认不改原文件；确认绑定展示的连接、路径和目标快照，发布前复核，检测到变化必须重新确认，不自动批准队列中的其他同名文件；界面说明复核后的并发修改仍可能未被检测，原子发布不保证版本条件原子成立

#### Scenario: 发布前取消或失败
- **WHEN** 上传尚未发布最终文件就取消、断线或写入失败
- **THEN** 原目标不被截断或预先删除，系统清理本任务可确认归属的临时文件；无法清理或无法确认发布结果时明确提示，不报告成功

#### Scenario: 服务端缺少安全替换能力
- **WHEN** 服务端不能提供本次覆盖所需的安全发布能力
- **THEN** 系统拒绝覆盖并提示选择新文件名，不使用先删除原文件再改名的方式冒充原子替换

### Requirement: 远端文件下载到本地
系统 SHALL 允许用户下载远端普通文件，通过浏览器正常下载/保存机制交付到本地电脑，不将后端服务器目录当作用户电脑目录，不要求 File System Access API 或一次性把整个文件加载进前端内存。本期支持逐文件下载，不提供目录递归打包。

#### Scenario: 下载二进制及中文文件
- **WHEN** 用户在文件面板下载普通文件
- **THEN** 文件通过有界流式传输交给浏览器，内容保持不变，文件名安全兼容 Windows；保存位置与本地覆盖由浏览器或用户决定

#### Scenario: 无法确认本地落盘
- **WHEN** 后端已经发送完下载内容但无法得知浏览器是否保存成功
- **THEN** 应用只显示“服务端发送完成／已交给浏览器”，不宣称已验证本地文件落盘

#### Scenario: 下载票据过期或并发使用
- **WHEN** 下载票据过期、被更换、重复消费，或两个请求同时尝试下载同一任务
- **THEN** 只有当前有效票据能原子领取尚未启动的任务，同一任务最多启动一个流，运行中和终态不能重新领票启动

### Requirement: 传输进度取消与资源隔离
系统 SHALL 展示文件方向、名称、大小、已传字节、进度与失败原因，允许取消排队及运行中任务；必须限制单文件大小、并发及缓冲占用，支持大于常见默认表单限制的文件。取消单个传输 MUST NOT 关闭同 tab 的人工终端或其他 tab。传输无进度超时 SHALL 为 300 秒（5 分钟），即连续 300 秒无字节进展则判定传输失败。

#### Scenario: 大文件与取消
- **WHEN** 用户传输大文件并在途中取消一个任务
- **THEN** 内存不随整个文件大小线性增长，该任务停止继续传输且显示取消或结果未知，其他任务和终端保持可用

#### Scenario: 关闭连接与断线
- **WHEN** 用户确认关闭所属连接或连接中断
- **THEN** 所属传输被清算并显示真实状态，不自动续传或覆盖远端文件，已发布文件不因取消操作被删除

#### Scenario: 排队和就绪领取
- **WHEN** 并发配额已满导致文件排队，或任务就绪后客户端迟迟没有开始传输
- **THEN** 排队期间不打开文件传输流或提前发放下载票据，只有就绪任务允许开始传输；就绪领取超时释放配额并提示，排队取消即时生效，不自动重传

#### Scenario: 大文件传输无进度超时
- **WHEN** SFTP 传输过程中连续 300 秒无任何字节进展
- **THEN** 系统判定传输失败，释放资源并显示失败原因，不无限等待

### Requirement: 路径权限与文件内容边界
系统 MUST 使用 SFTP 路径操作而非拼接 Shell 命令，校验远端绝对路径、文件名及连接控制权，拒绝越界参数、NUL、危险响应头及非普通文件传输。符号链接必须明确标识且本期不跟随；本地文件内容不得自动进入模型上下文或日志。

#### Scenario: 恶意文件名或链接
- **WHEN** 请求带有目录穿越文件名、换行响应头、指向符号链接的传输路径或特殊设备文件
- **THEN** 系统拒绝不安全请求，不执行拼接命令，不读取任意本地路径或跟随链接完成传输

#### Scenario: 手工传输与智能体隔离
- **WHEN** 用户上传或下载文件
- **THEN** 用户操作只授权该传输及已确认的覆盖，AI 不自动获得本地文件选择权、文件正文或额外远端命令执行权
